Vos alertes FUP dans Telegram

Connectez votre propre bot à votre organisation. Le nom du bot et votre Chat ID sont récupérés automatiquement. Aucun accès n8n n’est nécessaire.

1. Créer un bot dédié

  1. Ouvrez le compte officiel @BotFather dans Telegram.
  2. Envoyez /newbot.
  3. Choisissez un nom, puis un nom d’utilisateur terminé par bot, en suivant les indications de Telegram.
  4. Copiez le token fourni. Dans SafeLinkHub, ouvrez Paramètres → Notifications, collez-le dans le champ sécurisé et cliquez sur Vérifier mon bot.
Le token permet de contrôler votre bot. Collez-le uniquement dans SafeLinkHub. Ne le partagez pas dans un message, une capture ou un ticket de support. Il est chiffré et ne sera pas réaffiché.

2. Relier votre conversation privée

  1. Confirmez que ce bot est dédié à vos notifications, puis cliquez sur Connecter mon Telegram.
  2. Cliquez sur Ouvrir mon bot et appuyez sur Démarrer dans Telegram.
  3. Revenez dans SafeLinkHub et cliquez sur J’ai appuyé sur Démarrer — rechercher.
  4. Vérifiez le nom du destinataire et le Chat ID affichés, puis cliquez sur Confirmer ce destinataire.
  5. Cliquez sur Envoyer un test. Le message arrive dans cette conversation privée.

Le lien de liaison expire après dix minutes. Si vous fermez la page, générez un nouveau lien. Un simple message « bonjour » ne remplace pas le bouton Démarrer du lien personnel.

3. Activer vos alertes

Sélectionnez les routeurs de votre organisation et les catégories souhaitées : changements de niveau FUP, réserve ou quota épuisé, levée des limitations et bilan quotidien facultatif. Cliquez sur Activer les alertes.

La surveillance passe toutes les cinq minutes. Le bilan quotidien est préparé à partir de 07 h UTC et peut arriver plus tard en cas de panne ou de relevés retardés. Les consommations sont des estimations SafeLinkHub à rapprocher du relevé Starlink. Une levée de limites FUP ne confirme pas un renouvellement Starlink et ne lève pas une restriction contractuelle de l’opérateur.

Résoudre les problèmes courants

Token invalide
Recopiez-le depuis BotFather. Son remplacement dans SafeLinkHub impose une nouvelle connexion et un test avant réactivation.
Conversation introuvable
Ouvrez le lien personnel généré dans SafeLinkHub et appuyez sur Démarrer. Renouvelez le lien s’il a expiré, puis relancez la recherche.
Bot déjà utilisé par un autre service
Créez un bot dédié. Si votre conversation privée est déjà connue du bot, la configuration avancée permet de saisir le Chat ID et de confirmer le destinataire. SafeLinkHub ne supprime aucun webhook existant.
Message refusé
Débloquez votre bot dans Telegram. Relancez un test et réactivez les alertes si elles ont été désactivées après un échec permanent.
Où voir les échecs ?
La rubrique Derniers envois affiche les alertes en attente, envoyées, annulées ou en échec. Cliquez sur Actualiser l’état. Les tests ne figurent pas dans cette liste.

Déconnecter votre bot

Ouvrez Déconnecter ce bot puis confirmez. SafeLinkHub supprime le token, arrête les alertes et annule les envois en attente. Votre bot Telegram n’est pas supprimé.
