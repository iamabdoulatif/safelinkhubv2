MikroTik · RouterOS 7

Préparez votre MikroTik.

RouterOS stable, puis activation guidée des fonctionnalités. L’agent attend votre intervention physique entre les étapes qui l’exigent — les identifiants sont envoyés uniquement au routeur choisi.

1

Choisir le routeur

Détection sur le réseau local, ou saisie directe de l’adresse.

Routeur d’usine ou sans configuration ?

Branchez l’ordinateur sur un port LAN (souvent ether2), pas sur le port WAN. Avec la configuration d’usine, essayez 192.168.88.1 et le mot de passe de l’étiquette du routeur. Aucun compte de portail captif n’est requis pour l’administration.

Après un reset sans configuration, il peut ne rester ni IP ni DHCP : il faut d’abord initialiser un accès IP/API, par exemple avec WinBox par MAC. Cet agent HTTP/TCP ne peut pas créer cet accès à travers une API inaccessible.

Connexion chiffrée : le certificat TLS doit être valide pour l’IP du routeur.

Sur un réseau LAN de confiance : ce choix transmet les identifiants sans chiffrement. Aucun basculement automatique depuis TLS.

Autorité de certification privée (facultatif)

Sans Internet sur un routeur neuf, décochez cette option pour préparer les fonctionnalités avec la version déjà installée. La mise à jour sera indiquée comme différée.

Le routeur doit avoir accès à Internet pour télécharger RouterOS. Des coupures réseau sont normales pendant les redémarrages.

2

Suivre la préparation

Chaque étape n’est validée que par l’état relu sur le routeur.

  1. Vérifier la connexion administrateur
  2. Mettre RouterOS à jour (stable)
  3. Autoriser RouterBOARD
  4. Passer en mode avancé
  5. Activer container, hotspot, scheduler et fetch
  6. Vérifier le résultat

Aucune opération en cours.



      
L’ordre demandé est conservé. Le mode avancé peut annuler routerboard=yes : le rapport final le signalera. Cet outil n’installe pas le package container et ne met pas RouterBOOT à jour.
