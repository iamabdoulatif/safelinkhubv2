Connexion au routeur

Compte RouterOS (Winbox), pas celui du portail captif. Rien n’est modifié à cette étape, sauf le certificat qui chiffre la connexion (option avancée).

Routeur connecté

Routeur neuf : mot de passe imprimé sur l’étiquette (RouterOS 7). Changé avec l’agent ? Saisissez le nouveau.

Options avancées — port 8728, sans TLS

API 8728 : les identifiants circulent sans chiffrement sur le réseau local.

Routeur d’usine sans IP ni DHCP (après un reset sans configuration) : initialisez d’abord un accès avec Winbox par MAC. Branchez l’ordinateur sur un port LAN (souvent ether2), pas sur le WAN.

Plan de préparation

Vérifiez le routeur, choisissez les options, puis lancez.

Sans Internet sur un routeur neuf, décochez : les fonctionnalités sont préparées avec la version installée.

Paquets RouterOS à installer

Comme System › Packages dans Winbox : cochez les paquets voulus (container, zerotier, wifi-qcom…), décochez ceux à retirer. Appliqué après la mise à jour, en un seul redémarrage.

Coché = installé après l’opération, décoché = désinstallé (sauf routeros).

Exécution

Chaque étape n’est validée que par l’état relu sur le routeur.
